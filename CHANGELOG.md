# Changelog

## 0.1.0 - first version

- Loop engine with sample-accurate shared clock, count-in, metronome and quantized stop.
- Step sequencer, pads, mixer, sample browser with 29 synthesized starter sounds.
- Microphone / interface recording, clip editor with loop points, save as sample or loop track.
- Demucs-based stem separation with stem preview, mute/solo/volume and WAV/MP3 export.
- Projects (JSON), WAV/MP3 export of the mix and of single loops.
- GitHub Actions workflow: build, tests, self-contained win-x64 ZIP, releases on version tags.
